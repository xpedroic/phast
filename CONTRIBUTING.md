# Contributing to Phast / Contribuir a Phast

Thanks for your interest! / ¡Gracias por tu interés!

## How to propose improvements / Cómo proponer mejoras

1. **Open an issue** describing the bug or idea (screenshots help). / **Abre un issue** describiendo el fallo o la idea (las capturas ayudan).
2. **Fork** the repository and create a branch: `git checkout -b my-feature`.
3. Make your change. Keep the code style: one file per responsibility, comments in English. / Haz tu cambio respetando el estilo: un archivo por responsabilidad, comentarios en inglés.
4. Make sure it builds with no errors: `dotnet build` (or `build.bat`) and test it by running Phast. / Comprueba que compila sin errores y pruébalo.
5. Open a **Pull Request** explaining what it changes and why. / Abre un **Pull Request** explicando qué cambia y por qué.

## Rules / Reglas

- Third-party code must use a license compatible with Phast (MIT, Apache 2.0, BSD… — **no GPL**) and must be added to `THIRD_PARTY_NOTICES.md`. / El código de terceros debe tener licencia compatible (no GPL) y anotarse en `THIRD_PARTY_NOTICES.md`.
- Never commit personal data, passwords or tokens. / Nunca subas datos personales, contraseñas ni tokens.
- By contributing you agree that your contribution is distributed under the project's license (PolyForm Noncommercial 1.0.0). / Al contribuir aceptas que tu aportación se distribuya bajo la licencia del proyecto.
